Empires of Olympus — Windows
============================
Map dens + open cross-empire PvP build (Vulkan Forward+).

Athens / Sparta / Thebes are hostile from the start (free rival PvP).
Giant beast dens sit on the roads between capitals — press M for the map.

Settings → V-Sync Off, Max FPS Uncapped, Quality Balanced.
Enable Show FPS to verify.

Download: https://gofile.io/d/q0xhjxTi
