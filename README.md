# Empires-of-Olympus

Godot 4.4 Metin-style Greek MMO client: accounts, empire map, panoply,
Enter-to-chat, Minecraft-style server browser, and online host/join.

## Windows download

### Recommended (Defender-friendlier — no .exe in the zip)

**https://gofile.io/d/yZ5pik6Y** — `EmpiresOfOlympus-data-only.zip`

Extract → `powershell -ExecutionPolicy Bypass -File .\GET-ENGINE.ps1`

### Full zip

**https://gofile.io/d/S2MzFXG9** — `EmpiresOfOlympus-windows.zip`

This build includes the **Psifidoto of the Agora**, host peer-to-peer save
(joiners adopt the host world — no conflicts), parties, animated Q/R skills,
tutorial tips, plaza merchants, smith crafting, and post-Minotaur trials —
on the old-exe UAL motion baseline.

Run notes: [`docs/WINDOWS_RUN.md`](docs/WINDOWS_RUN.md)

## macOS download

**https://gofile.io/d/J12j72sy** — `EmpiresOfOlympus-macos.zip`

Universal app (Intel + Apple Silicon). If macOS says it “cannot be opened”,
double-click `OPEN-ON-MAC.command` after unzip (or see
[`docs/MACOS_RUN.md`](docs/MACOS_RUN.md)).
